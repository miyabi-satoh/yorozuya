# 再起動した先の進め方

- 引き継ぎ資料に書かれた前セッションの状態（再起動に取りかかる前の状態）を、そのまま引き継ぐ。会話ログの末尾にある再起動の依頼と返信は済んだやり取りなので、応じ直さない。
- 資料がプロジェクトの全体の流れの置き場を指していれば、続ける前に読む。立ち上げ直す手順が書かれたバックグラウンドの処理は、どの状態でも先に立ち上げ直す。
- 作業の途中なら、続きから再開する。計画（バックログ・ロードマップなど）の一部の途中なら、その一部を終えても止めず、残りへ順に進む。
- ユーザーの答えや操作を待っていたなら、同じ問いや頼みを前と同じ形（ダイアログならダイアログ、テキストならテキスト）で出し直して待つ。答えが返るまでは、現状を確かめる読み取りだけにとどめる。指示待ちなら、そのまま待つ。状態を読み取れなければ、推し量らずにユーザーに聞く。
- 外向きの操作や後戻りできない操作（push・PR・マージ・削除・他セッションへの依頼など）と、ユーザーの判断が要る論点は、資料に承認済みとあっても止めて聞く。ただし、ユーザーが CLAUDE.md や記憶で操作の種類ごとに前もって決めている扱いがあれば、そちらに従う（個々の操作を承認済みとした記録は含まない）。
