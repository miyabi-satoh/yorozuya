# 入れるもののジャンル

ステップ0の問い7で、1問ずつ聞く。

- 節ごとに、まず「1つずつ選ぶ / この節は全部おまかせ / この節は無し」の3択で聞く。おまかせは、各ジャンルで一番広く使われている候補を1つずつ選ぶこと
- 1つずつ選ぶなら、ジャンルごとに、今の OS で使える有名どころ 2〜3 個と「無し」を選択肢にして聞く（複数選んでよい）。選択肢で答える手段では「他のもの」が自動で付くので、自分では足さない。候補は知識から出してよいが、入れ方はステップ4で公式の情報を確かめる
- 今の環境に当てはまらない節（デスクトップの無い環境の GUI アプリやフォントなど）は、飛ばすと伝えて聞かない
- 最後に、ここに無いジャンルで入れたいものがあるかを聞く

ユーザーが自分の一覧を渡したら、それを使う。一覧に無いジャンルのうち、「シェル」「OS の設定」は、ここから聞く。ログインシェルを変えるかはステップ0の問い8、設定ファイルの管理ツールは問い5で聞くので、ここでは聞かない。

## GUI アプリ

- ブラウザ
- ターミナルエミュレータ
- ランチャー（アプリやファイルをキー操作で呼び出す）
- パスワードマネージャ
- クラウドストレージの同期
- ノート・ナレッジベース
- VPN・メッシュネットワーク
- リモートデスクトップのクライアント
- 仮想マシン
- データベースの管理ツール
- メディアプレイヤー
- BitTorrent クライアント
- キーボードのキーマップ設定ツール
- アンインストーラ（macOS。アプリと関連ファイルをまとめて消す）
- OS を拡張するユーティリティ集（Windows）

## CLI ツール

- バージョン管理と、Git ホスティングサービスの CLI
- コンテナの実行環境（GUI の版があれば、それも候補に出す。WSL では CLI の版）
- アーカイバ（多形式の圧縮・展開）
- GNU 互換のコマンド群（macOS / Windows）
- ファイル検索
- テキスト検索（grep の代わり）
- ファジーファインダ
- JSON の加工
- ディレクトリツリーの表示
- ターミナルのファイルマネージャ
- ターミナルのテキストエディタ
- ターミナルマルチプレクサ
- diff ビューア
- 動画・音声の変換
- PDF の処理（テキスト抽出・画像化）
- SVG のレンダリング
- ターミナルでの画像表示
- シェルのプロンプト
- ディレクトリの移動を速くするツール
- 言語やツールのバージョン管理（ランタイムを切り替える）

## 開発言語

使う言語と、その言語のパッケージマネージャを聞く。上の「言語やツールのバージョン管理」を選んだならそれで入れ、選ばなかったなら公式の手段で入れる。

## フォント

- プログラミング用の等幅フォント（アイコン入りの版があればそれも）
- 日本語を含む等幅フォント
- 資料や画像づくり用の日本語フォント

## シェル

- 入力を助ける拡張（入力候補の表示、構文の色付けなど）
- OS 標準より新しいシェル（Windows）

## OS の設定

- WSL: `/etc/wsl.conf`（自動マウント、ネットワーク、Windows との連携）を変えるか

## 設定ファイルの管理

ステップ0の問い5で、管理ツールの候補を出すときに使う。

- 設定ファイル（dotfiles）の管理ツール（symlink を張るもの、テンプレートから生成するものなど）
