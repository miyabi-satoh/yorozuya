# 入れるもののジャンル

ステップ0で、1問ずつ聞く。節ごとに、まずその節のものを入れるかを聞き、入れるならジャンルを1つずつ聞く。ジャンルの問いでは、今の OS で使える有名どころを 2〜4 個、知識から候補に出す（複数選んでよい）。候補は知識から出してよいが、入れ方はステップ4で公式の情報を確かめる。

- どの問いにも「無し」「他のもの」「この節の残りはおまかせ」「この節の残りは無し」を選べるようにする。おまかせは、そのジャンルで一番広く使われている候補を1つ選ぶこと
- 今の環境に当てはまらない節（デスクトップの無い環境の GUI アプリやフォントなど）は、飛ばすと伝えて聞かない
- 最後に、ここに無いジャンルで入れたいものがあるかを聞く

ユーザーが自分の一覧を渡したら、それを使う。一覧に無いジャンルのうち、「シェル」「OS の設定」「設定ファイルの管理」は、ここから聞く。

## GUI アプリ

- ブラウザ
- ターミナルエミュレータ
- ランチャー（アプリやファイルをキー操作で呼び出す）
- パスワードマネージャ
- クラウドストレージの同期
- ノート・ナレッジベース
- VPN・メッシュネットワーク
- リモートデスクトップのクライアント
- 仮想マシン
- データベースの管理ツール
- メディアプレイヤー
- BitTorrent クライアント
- キーボードのキーマップ設定ツール
- アンインストーラ（macOS。アプリと関連ファイルをまとめて消す）
- OS を拡張するユーティリティ集（Windows）

## CLI ツール

- バージョン管理と、Git ホスティングサービスの CLI
- コンテナの実行環境（GUI の版があれば、それも候補に出す。WSL では CLI の版）
- アーカイバ（多形式の圧縮・展開）
- GNU 互換のコマンド群（macOS / Windows）
- ファイル検索
- テキスト検索（grep の代わり）
- ファジーファインダ
- JSON の加工
- ディレクトリツリーの表示
- ターミナルのファイルマネージャ
- ターミナルのテキストエディタ
- ターミナルマルチプレクサ
- diff ビューア
- 動画・音声の変換
- PDF の処理（テキスト抽出・画像化）
- SVG のレンダリング
- ターミナルでの画像表示
- シェルのプロンプト
- ディレクトリの移動を速くするツール
- 言語やツールのバージョン管理（ランタイムを切り替える）

## 開発言語

使う言語と、その言語のパッケージマネージャを聞く。上の「言語やツールのバージョン管理」を選んだならそれで入れ、選ばなかったなら公式の手段で入れる。

## フォント

- プログラミング用の等幅フォント（アイコン入りの版があればそれも）
- 日本語を含む等幅フォント
- 資料や画像づくり用の日本語フォント

## シェル

- ログインシェル（変えるかどうかはステップ0で決める）
- 入力を助ける拡張（入力候補の表示、構文の色付けなど）
- OS 標準より新しいシェル（Windows）

## OS の設定

- WSL: `/etc/wsl.conf`（自動マウント、ネットワーク、Windows との連携）を変えるか

## 設定ファイルの管理

設定ファイルを持ってこないなら要らない。

- 設定ファイル（dotfiles）の管理ツール（symlink を張るもの、テンプレートから生成するものなど）
