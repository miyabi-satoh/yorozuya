# pick-three

文章で一問ずつ聞くより並べて見比べたほうが選びやすい判断を、1枚のページに並べて、ユーザーに選んでもらう。

## 読む前に

- **ページの出し方はエージェントで変わる。** Claude Code で Artifact ツールが使えるなら、アーティファクトとして出し、選んだ案と理由をアーティファクトの `db` に残して読む。使えないエージェントでは HTML ファイルをブラウザーで開き、選んだ案はチャットで返してもらう
- **実際に使ったのは Claude Code のアーティファクトだけ。** HTML ファイルで出す形は試していない
- **今ある画面を3通りに直して撮るには、ブラウザーの自動操作（Playwright など）が要る。** 無ければ HTML で再現する形になる

## できること

- 画面の配置・ダイアログの形・文言や言い回し・問題文の書き方・グラフの見せ方など、見て差が分かる判断で、3つの案を並べたページを出す。1つは一般的な形、残りの2つは方針を変え、それぞれに違いと損得を添え、推奨を1つ示す
- 選択肢の多い決定（範囲・並べ方・割り振りなど）や、いくつもの決定が絡み合うものでは、出所の選択肢をそのまま決定ごとに並べ、全体を1枚で見渡せるページを出す
- 選ばれた案と理由を、プロジェクトの決めごと（`docs/ui.md`・用語の表など）に書く。次に同じ種類の判断が出たら、3案を出さずにそれに従う
- 数行の文章で比べ終わるもの（二択・1つの値で決まるもの）や、一般的な形が1つに決まっているものでは、ページを作らない

## 使い方

見比べたほうが選びやすい判断で迷う場面では、エージェントが description を見て自分で使う。こちらから使わせるなら、「3案並べて」「ほかの案も見たい」「並べて見せて」のように頼む。
