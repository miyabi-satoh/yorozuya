# pick-three

見た目で選ぶ判断を、違いのはっきりした3つの案を1枚のページに並べて、ユーザーに選んでもらう。

## 読む前に

- **ページの出し方はエージェントで変わる。** Claude Code で Artifact ツールが使えるなら、アーティファクトとして出し、選んだ案と理由をアーティファクトの `db` に残して読む。使えないエージェントでは HTML ファイルをブラウザで開き、選んだ案はチャットで返してもらう
- **実際に使ったのは Claude Code のアーティファクトだけ。** HTML ファイルで出す形は試していない
- **今ある画面を3通りに直して撮るには、ブラウザの自動操作（Playwright など）が要る。** 無ければ HTML で再現する形になる

## できること

- 画面の配置・ダイアログの形・文言や言い回し・問題文の書き方・グラフの見せ方など、見て差が分かる判断で、3つの案を並べたページを出す。1つは一般的な形、残りの2つは方針を変え、それぞれに違いと損得を添え、推奨を1つ示す
- 選ばれた案と理由を、プロジェクトの決めごと（`docs/ui.md`・用語の表など）に書く。次に同じ種類の判断が出たら、3案を出さずにそれに従う
- 見た目に出ない設計（データの持ち方・API の形など）や、一般的な形が1つに決まっているものでは、ページを作らない

## 使い方

見た目の判断で迷う場面では、エージェントが description を見て自分で使う。こちらから使わせるなら、「3案並べて」「ほかの案も見たい」のように頼む。
